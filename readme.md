# Sistema de Empleados

Proyecto desarrollado en Python para administrar empleados.

## Funcionalidades
- Agregar empleados.
- Mostrar empleados.
- Buscar empleados.
- Modificar sueldos.
- Eliminar empleados.
- Guardar información mediante JSON.
Versión principal del proyecto.
